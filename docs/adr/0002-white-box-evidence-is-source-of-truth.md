# White-Box Evidence Is the Source of Truth

White-Box Findings must be grounded in structured White-Box Evidence, including entry points, sources, sinks, sanitizers, data-flow paths, file locations, and analyzer identifiers. Reproduction Documents are Markdown artifacts rendered from that evidence for review and document-guided verification; they are not the source of truth, because relying only on free-form Markdown or model summaries would make deduplication, regeneration, and anti-hallucination checks unreliable.
